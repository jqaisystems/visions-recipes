# Token Rain · design spec

Brand: JQ AI SYSTEMS (ai.joaoqueiros.com), dark theme.

## Palette
| Role | Hex |
|---|---|
| background | #111110 |
| surface (prompt field) | #1A1A18, border #2A2A27 |
| text | #F5F5F0 |
| body / draft tokens | #A3A39F |
| muted metadata | #6B6B68 |
| accent: teal (anti-pattern flags, critique gate) | #00A89D |
| secondary: blue (logo gradient end) | #0099D6 |

One accent (teal); blue appears only as the logo gradient's partner and in the particle palette.

## Type
- Geist 400/500/600: prompt response, lockup title.
- Geist Mono 400/500: prompt field, labels, metadata (uppercase, tracking .16em for labels).
- Instrument Serif: the final line only, "Same model. Your voice."

## Do
- Monospace metadata anchored to the frame edges (top rule, bottom counters).
- Additive teal/blue particle light on a near-black field.
- One eased drift on held text.

## Don't
- No beat punches or scale pulses on held text or the logo.
- No full-screen linear gradients (banding).
- No em dashes in copy (the flagged one on screen is the exception, and it is destroyed).
